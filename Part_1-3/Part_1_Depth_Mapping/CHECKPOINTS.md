# Model Checkpoints

The Depth Anything V2 ViT-L checkpoint is required but not stored in Git (large binary, ~1.4 GB).

## Download

- Model file: `depth_anything_v2_vitl.pth`
- Source: https://huggingface.co/depth-anything/Depth-Anything-V2-Large
- Place at: `Part_1_Depth_Mapping/checkpoints/depth_anything_v2_vitl.pth`

Or set the environment variable:

```
DA_CHECKPOINT_DIR=path/to/checkpoints
```
